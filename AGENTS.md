# Agents

## llms.txt

`llms.txt` is a machine-readable summary of this portfolio for AI crawlers. Keep it factual and short.

### When to update

Update `llms.txt` when any of these change:

- Name, role, or status (open to work / not)
- Stack (add/remove technologies)
- Experience entries (new job, updated highlights, changed responsibilities)
- Education
- Certifications
- Contact info (email, social links)
- Site description or what-is-this paragraph

### How to update

1. Match the exact structure already in `llms.txt`. Don't add new sections unless the site gains a genuinely new top-level area (e.g. a blog, a talks page).
2. Keep it under 200 lines. Cut ruthlessly. If a highlight is redundant with the summary, drop the highlight.
3. Use plain language. No marketing copy.
4. Run `npm run build` after editing to make sure nothing broke.

## Style rules

- No jargon. No "passionate", "leveraging", "synergy", "ecosystem", "cutting-edge", or similar filler.
- Write like a human talking to another engineer. Direct, specific, boring on purpose.
- Metric claims must have a source or be obviously placeholder. Don't invent numbers.
